# KES 5M Investment Tracker — Self-Hosting / Setup Guide

This ZIP contains the **complete source** of the KES 5M Investment Tracker
(React 19 + Tailwind 4 + Express 4 + tRPC 11 + Drizzle ORM on MySQL/TiDB).
It is everything needed to copy-paste and run the exact system elsewhere.

> `node_modules/`, build output and local logs are intentionally excluded —
> they are regenerated by `pnpm install`. Everything else (source, config,
> database schema, migrations, lockfile, tests) is included.

---

## 1. Prerequisites

- **Node.js 22.x** (or >= 20.9)
- **pnpm 9+** (`npm i -g pnpm`)
- A **MySQL 8 / TiDB** database (any provider, or local MySQL)

## 2. Install dependencies

```bash
pnpm install
```

## 3. Environment variables

Create a `.env` file in the project root. The app reads these (see
`server/_core/env.ts` for the authoritative list):

```bash
# ── Database (required) ──────────────────────────────────────────────
DATABASE_URL="mysql://user:password@host:3306/kes5m_tracker"

# ── Auth / sessions (required) ───────────────────────────────────────
JWT_SECRET="generate-a-long-random-string"

# ── Manus OAuth (required for login) ─────────────────────────────────
# If you are running OUTSIDE the Manus platform you must supply your own
# OAuth/identity provider or stub these. They originate from the platform.
VITE_APP_ID="your-oauth-app-id"
OAUTH_SERVER_URL="https://api.manus.im"
VITE_OAUTH_PORTAL_URL="https://manus.im/login"
OWNER_OPEN_ID="owner-open-id"
OWNER_NAME="Owner Name"

# ── Manus built-in APIs (LLM, storage, image, notifications) ─────────
# Optional unless you use those features. Without them, LLM/image calls fail
# gracefully but the core tracker (deposits, accrual, tax, reconciliation)
# works fully since all financial math is local & framework-free.
BUILT_IN_FORGE_API_URL=""
BUILT_IN_FORGE_API_KEY=""
VITE_FRONTEND_FORGE_API_KEY=""
VITE_FRONTEND_FORGE_API_URL=""

# ── App branding (optional) ──────────────────────────────────────────
VITE_APP_TITLE="KES 5M Investment Tracker"
VITE_APP_LOGO=""
```

> **Important:** All the core investment logic — daily accrual (geometric
> compounding for MMF/bank, straight-line coupon for gov securities), tiered
> WHT, tax summary, reconciliation, Est. Interest Earned and Est. Annual Tax —
> is pure TypeScript in `shared/` and runs without any external API.

## 4. Create the database schema

The Drizzle schema lives in `drizzle/schema.ts` and generated migration SQL in
`drizzle/migrations/`. Apply it with:

```bash
# Option A — push the schema directly (simplest for a fresh DB)
pnpm drizzle-kit push

# Option B — generate + run SQL migrations
pnpm drizzle-kit generate
# then execute the .sql files in drizzle/migrations/ against your DB
```

## 5. Run

```bash
# Development (Vite + Express, hot reload)
pnpm dev
# → http://localhost:3000

# Production build + start
pnpm build
pnpm start
```

The server binds to `process.env.PORT` (default 3000). Never hardcode the port.

## 6. Tests

The full deterministic test suite (financial engines, reconciliation,
cross-page tie-outs) runs with:

```bash
pnpm test          # vitest run
pnpm exec tsc --noEmit   # type check
```

## Notes on Manus-specific integrations

This app was built on the Manus platform. The following depend on Manus
services and will need substitution if self-hosting fully standalone:

- **Login** — Manus OAuth (`server/_core/oauth.ts`). Swap for your own IdP.
- **LLM / image generation / voice / notifications** — `server/_core/*`.
  These are optional; the tracker's core does not require them.
- **File storage** — `server/storage.ts` proxies to Manus storage; repoint to
  your own S3-compatible bucket if needed.

Everything else is standard, portable Node/React.
